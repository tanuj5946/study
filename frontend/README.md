# StudySync — Frontend

React + Vite frontend for the StudySync learning platform.

## Setup

### 1. Install dependencies
```bash
npm install
```

### 2. Create `.env` file
```env
VITE_API_URL=http://localhost:5000
```

### 3. Start the dev server
```bash
npm run dev
```

Open `http://localhost:8080` in your browser.

## Features
- Module-based learning with sequential unlocking
- Mini tests to unlock next modules
- Subject tests with difficulty selection
- Analytics with charts and exportable results
- AI-powered recommendations and Hinglish chatbot
- Study planner
- Admin panel for managing questions, modules and notes
